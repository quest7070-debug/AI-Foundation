## O. Long-term operation / aging / resource-lifecycle audit
This section is a mandatory durability gate for unattended month/year-scale use. Passing short regression, restart, or component-health checks does not satisfy it. Where waiting for wall-clock time is impractical, use deterministic accelerated-time, high-cardinality, high-volume, repeated-lifecycle and fault-injection tests, then retain bounded production telemetry/readback.

# Verified artifact
Use when the task asks to create or transform a text, CSV, Markdown, or JSON deliverable.

1. Identify the required output format, input provenance and acceptance checks.
2. Read source inputs only through the existing host-authorized FILES or DATA tools where available.
3. Compute structured results with the existing bounded DATA capability when authorized; do not guess calculations.
4. Produce the artifact within the existing approved output scope, if any. Tool availability never implies write permission.
5. Where a write occurs, verify the resulting current content using an independent authorized readback before claiming saved.
6. Separate successful local drafting from successful persistence or delivery; report unresolved checks explicitly.
